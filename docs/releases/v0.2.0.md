# PlanHaven v0.2.0

Roadmap phase 0.2 is complete. Security review: `docs/releases/v0.2.0-security-review.md`.

## New since v0.1.1

- **Contacts:** contractors and suppliers, each shared one by one, with Call and Email
  buttons.
- **Quotes and costs** on projects: quotes (requested, received, accepted, declined) with a
  contact and a document; money spent with a running total. Amounts in Canadian dollars.
- Removing someone from a project now disconnects them from its open notes immediately.
- Refused live-editing attempts are recorded in the security log.

## Everything in phase 0.2

Sharing, lists, live notes, photos and files (location removed), assets with service
history, contacts/quotes/costs, installable app, trash (30 days), offline lists. Details in
`docs/releases/v0.1.1.md` and `docs/roadmap/phase-0.2.md`.

## Upgrade notes

- Database migrations run automatically on start (up to revision 0016).
- `/data` holds attachments; keep it in your backups.
