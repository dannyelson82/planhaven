# PlanHaven v0.1.1

Everything built in roadmap phase 0.2 so far (see `docs/roadmap/phase-0.2.md`). Contacts,
quotes and costs, and the full phase security review, follow in v0.2.0.

## New

- **Sharing:** share a project with household members as owner, editor or viewer. Changing
  who can see a project needs a fresh second factor.
- **Lists:** shopping, parts and checklist lists with one-tap check-off.
- **Notes:** rich-text notes edited live by several people at once, with each other's cursors.
- **Photos and files:** attach files to a project or take a photo on the phone. Photo location
  (GPS) and camera details are removed by default.
- **Assets:** vehicles, boats, the house and other things you look after, with details, their
  own sharing, and the linked projects as service history.
- **Installable app:** add PlanHaven to the phone's home screen.
- **Trash:** deleted things can be restored for 30 days, then they're removed for good.
- **Offline lists:** lists open without a connection; items added or checked off offline are
  sent when back online, and anything that can't be saved is listed.

## Upgrade notes

- Database migrations run automatically on start (revisions 0010–0015).
- Attachments are stored under `/data`. Make sure it is mapped to a share and included in
  your usual backups (`docs/backup-restore.md`).
- The built web files moved from `/assets/` to `/static/`. If a reverse proxy has rules for
  `/assets/`, update them.

## Security notes (SECURITY.md §11, spot check for a point release)

- Every new route is in the authorization matrix; every new table has row-level security
  enabled and forced; all CI security gates and the browser tests (zero CSP violations) pass.
- New attack surface and its controls: real-time editing over WebSockets (§7.15: Origin
  check, session at connect, re-checked every 15 s, size/rate/connection limits); uploads
  (§7.5: type from bytes, allowlist, size and rate limits, image decoding in a
  resource-limited subprocess, downloads sandboxed); offline copies on phones (§7.14: no
  credentials stored, wiped on sign-out).
- New runtime dependencies: `pycrdt`, `websockets`, `Pillow` (all permissive licenses).
- Still open from v0.1.0: the accepted `libxml2` exception
  (`docs/releases/v0.1.0-security-review.md`) until Debian ships a fix.
