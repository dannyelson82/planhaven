the evidence is; every "tested" item runs automatically on every pull request.

## Open items

**Unfixed critical in the base image (criteria 3 and 9).** Trivy reports CVE-2026-6653
(`libxml2`, denial of service) in Debian 13 with no fixed version available. Planhaven doesn't
parse XML with libxml2 (PostgreSQL links it for XML functions the app never calls), and the
database isn't reachable from the network. CI already fails on any critical that *has* a fix,
and re-scans weekly. **Accepted by the maintainer on 2026-09-27** as a documented exception for
v0.1.0, to be cleared as soon as Debian ships a fix (the weekly scan will then fail until the
image is rebuilt).

**Low: `Cross-Origin-Embedder-Policy` header missing** (ZAP). Optional hardening; no
cross-origin content is used. Consider adding with the plugin UI iframes (phase 0.7).
