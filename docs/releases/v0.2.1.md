# Planhaven v0.2.1

Improvements from real-world testing after v0.2.0.

## New

- **iPhone photos (HEIC)** can be uploaded. They're converted to JPEG with the location
  removed, like other photos (or kept as they are if you tick "keep location").
- **Lists:** an Edit button to rename items and change quantities. Delete buttons only
  appear in edit mode, and a deleted item can be brought back with Undo.
- **Tasks can need items from the project's lists.** The task shows what's still to get
  ("Needs 1 of 3 items: ...") until everything is checked off.
- **Note checkboxes can be ticked from the project page**, without opening the note.

## Upgrade notes

- Database migration 0017 runs automatically on start.
- The image now includes libheif's HEIC decoder (LGPL, decoder only; see SECURITY.md §7.5).
